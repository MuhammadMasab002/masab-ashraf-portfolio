# @workspace/api-client-react

Auto-generated **TanStack React Query** hooks and fetch client for frontend applications.

---

## 🚀 Overview

`@workspace/api-client-react` provides type-safe React Query hooks and custom fetch logic generated directly by **Orval** from `packages/api-spec/openapi.yaml`. It simplifies data fetching, caching, and state synchronization with `@workspace/api-server`.

> ⚠️ **Note:** Do not manually edit files inside `src/generated/`. These files are automatically updated when running the codegen script.

---

## 📁 Directory Structure

```
packages/api-client-react/
├── src/
│   ├── index.ts               # Package entry point
│   ├── custom-fetch.ts        # Custom fetch wrapper handling base URLs & headers
│   └── generated/             # Auto-generated by Orval
│       ├── api.ts             # React Query hooks (e.g. useGetHealthz)
│       └── api.schemas.ts     # TypeScript models for request & response types
├── tsconfig.json
└── package.json
```

---

## 🔄 Generation

To regenerate the hooks after modifying `packages/api-spec/openapi.yaml`, run:

```bash
pnpm --filter @workspace/api-spec run codegen
```

---

## 💻 Usage Example

In React / Next.js client components:

```tsx
'use client';

import { useGetHealthz } from "@workspace/api-client-react";

export function SystemStatus() {
  const { data, isLoading, error } = useGetHealthz();

  if (isLoading) return <div>Checking system status...</div>;
  if (error) return <div>Failed to connect to API</div>;

  return <div>API Status: {data?.status}</div>;
}
```
