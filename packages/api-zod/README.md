# @workspace/api-zod

Auto-generated type-safe **Zod** validation schemas derived from the OpenAPI specification.

---

## 🚀 Overview

`@workspace/api-zod` contains Zod schemas generated automatically by **Orval** from `packages/api-spec/openapi.yaml`. It provides runtime validation for incoming requests and outgoing responses in `@workspace/api-server`.

> ⚠️ **Note:** Do not manually edit files inside `src/generated/`. These files are automatically updated when running the codegen script.

---

## 📁 Directory Structure

```
packages/api-zod/
├── src/
│   ├── index.ts               # Package entry point re-exporting generated schemas
│   └── generated/             # Auto-generated by Orval
│       ├── api.ts             # Zod route schemas (e.g. HealthCheckResponse)
│       └── types/             # Associated TypeScript types
├── tsconfig.json
└── package.json
```

---

## 🔄 Generation

To regenerate this package after modifying `packages/api-spec/openapi.yaml`, run:

```bash
pnpm --filter @workspace/api-spec run codegen
```

---

## 💻 Usage Example

In `@workspace/api-server`:

```typescript
import { Router } from "express";
import { HealthCheckResponse } from "@workspace/api-zod";

const router = Router();

router.get("/healthz", (_req, res) => {
  // Validate and parse response data
  const data = HealthCheckResponse.parse({ status: "ok" });
  res.json(data);
});
```
